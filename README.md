# Atelier Richard Méchano

Bilingual (FR/EN) premium spare-parts ecommerce site — Apple.com-grade aesthetic, payment-proof checkout flow, full admin dashboard. Built with Next.js 16.4.0 (App Router), React 19.3.0, TypeScript, Tailwind CSS v4, Mongoose 9, Cloudinary, Nodemailer + React Email, jose, zustand, zod, motion, Font Awesome 7.3.1 only.

**Français :** ce dépôt contient le site complet atelier-richard-mechano.com — catalogue de pièces détachées d'occasion avec fiche produit, panier, commande avec preuve de paiement, suivi, blog, FAQ et back-office. Tout est bilingue français/anglais (bascule de langue dans la barre de navigation, cookie `arm-locale`, défaut FR). Voir [docs/BILINGUAL.md](docs/BILINGUAL.md) pour le fonctionnement i18n.

## Quick start

```bash
npm i
cp .env.example .env.local   # fill in the values (a working .env.local is already provided locally)
npm run dev
```

Open http://localhost:3000 — admin at http://localhost:3000/admin/login.

## Environment (`.env.local`)

| Variable | Purpose |
| --- | --- |
| `MONGODB_URI` | MongoDB Atlas. Without it the site falls back to `data/*.json` files. |
| `AUTH_SECRET` | JWT secret for the `arm-admin` session cookie. |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | Bootstrap admin login. Defaults: `admin@atelier-richard-mechano.com` / `Mechano2026!` — **change in production**. |
| `SITE_URL` / `NEXT_PUBLIC_SITE_URL` | Canonical origin (metadata, OG, JSON-LD, sitemap). |
| `CLOUDINARY_*` | Signed direct-to-Cloudinary uploads (products + payment proofs). Optional — falls back to local `data/proofs/` storage served by `/api/proofs/[ref]/[file]`. |
| `SMTP_*` / `EMAIL_FROM` / `NOTIFICATION_EMAIL` | Gmail SMTP (`smtp.gmail.com:587`, STARTTLS). Without SMTP, emails are written to `data/emails/` for inspection. |

Env always wins over the values saved in Admin → Settings.

## What's inside

- **Storefront** — home, `/shop` (URL-driven filters: q/make/brand/category/condition/price/stock/sort, linkable + back/forward), product pages (gallery, compatibility, specs, related, product JSON-LD), cart drawer + cart page, checkout with delivery/pickup and payment methods, `/checkout/success/[ref]`, `/track` (reference + email lookup, timeline, payment-proof upload, proof approve/reject states).
- **Payment proof flow** — per-order `proofMethod: email | upload`; the customer uploads a JPG/PNG/WebP proof on the track page (10 MB max), an admin notice email fires, and the dashboard approve/reject queue sends localized feedback (approve → *Payment Received*, reject → *Awaiting Payment Proof* with reason).
- **Content** — bilingual blog, FAQ page with search + FAQ JSON-LD, about/contact/quote/affiliate/testimonials/legal pages, testimonials with public review submission + admin moderation.
- **Admin** (`/admin`, session-guarded) — overview stats + proof queue, orders (search, status filter, status editor, instructions email, proof review, history), parts CRUD (Cloudinary uploader, drafts, featured), blog CRUD, category/make/brand tiles, review & enquiry moderation, settings (identity, payment methods FR+EN, delivery, integrations status). Tables collapse into tiles on small screens; admin chrome is English by design.
- **i18n** — cookie-driven FR/EN switch, dictionaries typed for parity (`fr.ts` is the source of truth), localized emails driven by the order's stored language, locale-aware currency/date formatting.
- **SEO/quality** — localized metadata + OG images, Organization/Product/FAQ JSON-LD, sitemap + robots, skip link, WCAG 2.2 AA-minded semantics, `prefers-reduced-motion` honoured everywhere.
